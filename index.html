One year in, five apps out

A short version of the résumé — who I am, what I ship, and how I work.

Flutter developer with 1 year of hands-on experience building, testing and deploying scalable cross-platform applications with Flutter and Dart.

I work across the full lifecycle: RESTful API integration, Provider and Bloc state management, PostgreSQL and SharedPreferences persistence, responsive UI development, geolocation services, PDF generation and performance optimisation. So far that has meant 5+ production-ready Flutter apps and 2 web applications, delivered inside Agile, cross-functional teams.

Day to day I turn Figma files into pixel-accurate screens that behave the same on Android and iOS, wire them to real backends, and then stay with them — profiling, debugging and tuning until the release is stable. Git and GitHub run the whole loop: branches, reviews, sprint delivery.

Outside the mobile stack I build for the web with Angular and TypeScript, make games in Unity, model 3D objects in Blender, edit video and photos, and keep growing my networking and Linux fundamentals. Quick learner, calm debugger, and happiest when a build finally ships.
